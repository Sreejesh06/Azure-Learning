# Exercise - Build a RAG document store on Azure Cosmos DB for NoSQL

In this exercise, you will set up a document store designed to support a Retrieval-Augmented Generation (RAG) pattern. RAG enhances AI model responses by retrieving relevant documents from a database and providing them as context to the model.

## Prerequisites

- An active Azure subscription.
- Azure CLI installed.
- Python 3.8+ installed.

## Step 1: Provision Cosmos DB

Create an Azure Cosmos DB account and a database with a container. Choose a partition key suitable for your document structure (e.g., `/categoryId`).

## Step 2: Implement the SDK

Write a Python script to connect to the Cosmos DB account. You will need to implement functions to:
1. Initialize the client.
2. Insert sample documents (e.g., product manuals, FAQs).
3. Query the documents based on specific criteria.
