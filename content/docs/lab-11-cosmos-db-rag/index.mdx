# Build queries for Azure Cosmos DB for NoSQL

Learn how to connect to Azure Cosmos DB for NoSQL using the SDK, perform data operations on items, and write efficient SQL queries to retrieve document data for AI applications.

## Learning objectives

After completing this module, you'll be able to:
* Connect to Azure Cosmos DB for NoSQL using the SDK.
* Perform data operations on items in Cosmos DB.
* Write efficient SQL queries to retrieve document data for AI applications.
* Build a RAG (Retrieval-Augmented Generation) document store on Azure Cosmos DB for NoSQL.
