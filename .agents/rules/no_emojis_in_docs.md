---
description: "Guidelines for writing documentation and MDX files without emojis."
---

When generating, modifying, or writing documentation (especially files in the `content/` folder), strictly avoid using emojis. The core focus must always be on the actual technical content, command accuracy, and learning points. High-quality content and detailed troubleshooting steps are what matter most, as that is what is actually shown in the deployed documentation site. Do not include alert emojis or any other decorative emojis in headings, paragraphs, or lists.
